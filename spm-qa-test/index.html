QA Status Panel & Execution Guide

Chrome Extension Integration Testing

  1. Open Chrome and navigate to chrome://extensions/.
  2. Enable Developer mode in the top right.
  3. Click Load unpacked and select the extension directory.
  4. Click any test link above and open the SPM extension popup to inspect DOM extractions.

Automated Testing (Playwright / Vitest)

  • Run unit and component tests: npm test or npx vitest
  • Run E2E test suites against these synthetic files: npx playwright test
  • Inspect engine sanitization logs in the browser developer console (F12).
